# Household Energy-Conserving Behaviour in Sri Lanka — Survey Data & Analysis Code

Data and fully reproducible analysis code for a survey of **70 Sri Lankan
households**, accompanying the preprint:

> **Many Habits, Not One Disposition: The Multidimensionality of Household
> Energy-Conserving Behaviour in Sri Lanka**
> Oshan Mudannayake — Department of Computer Science & Engineering,
> University of Moratuwa, Sri Lanka
> ([ORCID 0000-0002-9598-457X](https://orcid.org/0000-0002-9598-457X))

The code regenerates **every figure and table** in the paper from the raw data.

## Please read before using the data

This is a small, exploratory study. Three framing points are essential and easy to
get wrong:

- **Electricity consumption was never measured** — there are no kWh, no bill
  amounts, no tariff blocks. The outcomes are **five self-reported
  energy-*conserving* behaviours** (bill-calculation literacy, ironing efficiency,
  night-lighting restraint, meter-checking frequency, appliance energy-rating
  awareness). Monthly expenditure is only a coarse socio-economic-status proxy.
  **Do not read anything here as a claim about energy use or savings.**
- **The five behaviours do not form a single reliable trait** (Cronbach's
  α ≈ 0.06; near-flat PCA). They are analysed as **independent** outcomes; the
  composite Energy-Consciousness Index (ECI) is descriptive only.
- **The sample is a non-probability convenience sample** (N = 70), heavily skewed
  (≈ 81 % male, 83 % "Professional", 60 % university, 57 % Western Province; zero
  respondents from Northern / North-Central / Uva). All analysis is exploratory,
  effect-size-led, and FDR-controlled; no result generalises to Sri Lankan
  households at large.

## Privacy / de-identification

No directly identifying information (names, contact numbers, addresses, GPS, age)
was ever collected. To further protect respondent confidentiality in such a small
sample, the **finest-grained geographic field — the divisional secretariat — has
been removed** from the released data. That field is never used anywhere in the
analysis, so its removal does **not** affect reproducibility of any published
figure or table. District and province (which the representativeness analysis
relies on) are retained.

## Repository layout

| Path | What it is |
| ---- | ---------- |
| `data/raw/survey.csv` | De-identified source data: **70 households × 26 items**, original survey-question headers. See `data/raw/README.md`. |
| `data/processed/` | Generated by `code/00_clean.py`: `cleaned.csv`, `codebook.csv` (the data dictionary), `eci_scores.csv`, `clean_summary.json`. |
| `code/lib/` | Shared library: `config.py` (paths, column map, variable roles, the ECI rubric), `io.py`, `stats.py`, `plotting.py`. |
| `code/00_clean.py` | Cleaning + Energy-Consciousness-Index construction. |
| `code/01…09_*.py` | One script per analytic theme (sample quality, dwelling, SES, energy systems, behaviours, associations, typologies, undirected + targeted inference). |
| `code/run_all.py` | Regenerates every processed table, figure, and analysis output. |
| `code/outputs/figures/` | Generated figures (PNG + vector PDF). |
| `code/outputs/tables/` | Generated tables (CSV + LaTeX). |

Generated outputs are **committed** to this repository, so you can browse the
results without running anything.

## Reproduce the analysis

Requires [`uv`](https://docs.astral.sh/uv/) (Python 3.12). From `code/`:

```sh
cd code
uv sync                      # create the pinned Python 3.12 env
uv run python run_all.py     # clean + run all themes -> data/processed + outputs/
```

All random seeds are fixed, so bootstrap intervals and clustering are exactly
reproducible. Outputs are overwritten in place under `data/processed/` and
`code/outputs/{figures,tables}/`.
